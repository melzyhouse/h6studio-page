## 1. 제품 팩트

- **포지션**: "놀라운 Mac을 놀라운 실속으로" — 입문용/학생용 Mac, 첫 Mac 사용자 타깃
- **가격**: 1,200,000원부터 (교육 할인 프로모션 노출)
- **칩**: A18 Pro (iPhone 칩) — Apple Intelligence 지원
- **디스플레이**: 33.0cm(13") Liquid Retina, 500니트, 10억 색상, 3,600만 픽셀
- **배터리**: 최대 16시간
- **색상**: 실버 · 블러시 · 시트러스 · 인디고 (키보드까지 깔맞춤)
- **포트**: USB 3(USB‑C) 1, USB 2(USB‑C) 1, 3.5mm 헤드폰 잭
- **기타**: 1080p FaceTime HD 카메라, 듀얼 사이드 파이어링 스피커(Dolby Atmos), 듀얼 마이크, Touch ID 또는 잠금 키 모델, 재활용 소재 60%(알루미늄 90% 재활용)
- **비교 대상**: MacBook Air 13·15 (M5, 18시간, Thunderbolt 4 ×2 + MagSafe 3)

## 3. 카피 톤 (한국어)

- **짧은 명사형 종결 + 마침표**: "일단 핵심부터." "작업의 선수." "타협은 없다." "안심 그 자체."
- **구어체·말맛**: "열자마자 와우." "고고고." "똑소리 나게." "야무진 능력", "잽싸게", "복붙", "깔 맞춤"
- **대구/리듬**: "시각 청각 모두 매혹." "유용함에 경쾌함까지." "여기서 시작하고, 저기서 끝내고."
- **헤드라인은 감성, 본문은 친절한 ~습니다/~죠 체**: 본문 끝을 "~할 수 있죠." "~그야말로 마법 같죠."로 부드럽게 맺음
- **타깃 언어**: 학업·방과 후·과제 발표·첫 Mac·PC에서 갈아타기 → 학생/입문자 중심
- 숫자·스펙은 카피에서 분리해 **stat 블록**(작은 캡션 + 거대한 숫자)으로 보여줌. 각주 번호(1~12, *, ◊)를 꼼꼼히 붙임

## 4. 디자인 시스템 핵심

### 타이포그래피
- 한국어는 **SF Pro KR**, 20px 이상은 SF Pro **Display**, 19px 이하는 SF Pro **Text**
- 굵기는 거의 **600(semibold)** 하나 + 본문 400. 설명 문단도 600으로 굵게 씀(`typography-ps-body`)
- 큰 글씨일수록 **letter-spacing 음수**(-0.015em), 작은 글씨는 거의 0 또는 살짝 음수
- 스케일 (large/medium/small): 96/80/48 · 48/40/32 · 28/24/21 · 24/21 · 21/19 · 17/14 · stat 80
- 화면이 줄어도 비율이 아니라 **단계별 고정값**으로 점프

### 색
- 텍스트 `#1d1d1f`(순검정 아님), 보조 `#6e6e73`/`#86868b`
- 배경은 흰색 / `#f5f5f7` / 다크 `#1d1d1f` 3가지뿐
- 포인트 블루 `#0071e3` (버튼), 링크 `#0066cc`
- 색은 제품 사진과 **그라디언트 텍스트**가 담당: 섹션 헤드라인이 스크롤 시 `#1d1d1f`에서 제품 컬러(시트러스 그린, 인디고 블루, 블러시 핑크 등) 그라디언트로 스윽 물드는 효과 (`.gradient-text` + `background-clip:text` + `background-position` 2초 트랜지션)

### 레이아웃·컴포넌트
- 브레이크포인트 3단: 1069px↑ / 735–1068px / 734px↓ (+1441px↑, 480px↓)
- 콘텐츠 폭 980px, 와이드 1260px, 섹션 상하 패딩 144→120→112px (여백이 매우 큼)
- 카드 radius **28px**, 버튼 pill(999px), 스와치 원형
- 주요 컴포넌트(`data-component-list`): `MediaCardGallery`(가로 스크롤 카드), `CaptionTileGallery`, `ProductViewer`, `VideoScrub`(스크롤에 맞춰 영상 재생), `StaggeredFadeIn`(순차 페이드인), `Modal`, `TextOverMedia`, 탭 네비 + 페이드 갤러리
- 갤러리는 우하단 원형 화살표 패들(`paddlenav`) + 일시정지 버튼

### 모션
- 기본 이징 `cubic-bezier(0.66, 0, 0.1, 1)` — 빠르게 시작해 길게 감속
- 스크롤 트리거: 요소가 뷰포트에 들어오면 아래→위 + 페이드인(stagger), 그라디언트 텍스트 활성화
- 스크롤 고정(sticky/pin) + 영상 스크럽

## 5. 따라 만들 때 체크리스트

1. 섹션 = 아이브로 + 96px 헤드라인 + 21px 볼드 설명 + 미디어 공식 유지
2. 색은 3배경 + 1블루만. 화려함은 이미지/그라디언트 텍스트에 맡기기
3. 여백을 과감하게(섹션 패딩 140px 내외)
4. 카피는 짧게, 마침표로 끊고, 숫자는 stat으로 분리
5. 스크롤 페이드인과 감속 이징으로 "느긋한 고급감"
6. `demo.html`에서 실제로 적용한 예시 확인

> 참고: `raw/`의 원본과 이미지·영상·카피는 Apple 저작물입니다. 학습·분석용으로만 쓰고, 실제 작업에는 패턴과 원칙만 가져가세요.
